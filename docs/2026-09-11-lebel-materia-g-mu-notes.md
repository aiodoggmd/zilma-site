# Заготовка для статей MATERIA G и MATERIA μ

Собрано 11.09.2026 по ходу работы над статьёй о базовой MATERIA. **В ту статью это
намеренно НЕ вошло** — правило пользователя: три красителя Lebel разделены на три статьи,
и всё, что относится к G и μ, ждёт своей.

Осторожно с источниками: русскоязычные руководства по MATERIA валят все три линии в один
текст, и оттуда легко перетащить в статью чужой факт. Каждый пункт ниже помечен линией, к
которой относится.

## MATERIA G (седина)

- Оттенки **на 0,5–1 тон темнее** классической MATERIA — то есть номер тот же, результат
  глубже. Источник: руководство oknoinjapan.com.
- **Стандартная пропорция 1+1** с MATERIA OXY W — официальная карта Takara Belmont
  (`Работа/Lebel/color-charts/MATERIA-G-color-chart-takarabelmont.pdf`, текстовый слой
  читается напрямую).
- **Официальный процесс из восьми шагов** — на той же карте, на английском: подбор →
  замешивание → консультация → нанесение → выдержка 30 минут → цветовая проверка →
  эмульгирование → шампунь и уход. Плюс патч-тест за 48 часов, защитный крем на кожу и
  сглаживающее масло. (В статье о базовой MATERIA этот процесс уже описан как общий для
  серии — при написании G не подавать как новость.)
- **Три shade group** с официальными формулировками: Brown Shades — натуральный цвет на
  любой седине; Texture Shades — нюансированный цвет и anti-aging, воздушность и блеск;
  Primary Shades — усиленный цвет «как в fashion».
- **Таблица смешивания соседних уровней** прямо на карте: K-10 + K-8 → 2:1, O-10 + O-8 →
  2:1, G-10 + G-8 → 3:1, M-10 + M-8 → 2:1, A-10 + A-8 → 2:1, V-10 + V-8 → 2:1,
  P-10 + P-8 → 2:1, CA-10 + CA-8 → 2:1, R-10 + R-8 → 2:1, и такой же блок для пар 8+6.
  Это готовые формулы промежуточных уровней — сильный материал для статьи.
- **Код G читается иначе**: пример с карты «C9-3G → CB / тон, 3 / яркость».
- **MATERIA G Integral Line** — отдельная подлиния, своя карта
  (`MATERIA-G-integral-line.pdf`), код вида «Pt-4G → Pt / тон, -4 / яркость».
- В прайсе Zilma линия идёт строками **«Краска д/волос NEW G»** (15 позиций на 11.09.2026).
- Палитра с фото-свотчами уже собрана прежней сессией:
  `src/data/lebel-materia-g-shades.json` + `public/images/shades/lebel-materia-g/`.
  **Перед использованием проверить так же, как проверялась базовая MATERIA** — в её файле
  нашлись выдуманный оттенок и неверный код, см. `scripts/build-materia-shades.py`.

## MATERIA μ (мягкое тонирование)

- **Пропорция 1+1 строго с OXY W 3%** — официальная карта MATERIA (легенда внизу).
- На карте базовой MATERIA оттенки, доступные и в μ, помечены **синим квадратом** — по
  ним и собирается палитра μ, отдельной карты в наших материалах нет.
- **CLRμ** — прозрачный разбавитель линии, стоит в контрольной колонке карты рядом с
  LT и LT-EX.
- Характеристика из руководства oknoinjapan.com: полуперманентный краситель с двойной
  дозой коллагена и эффектом ламинирования. **Проверить по официальному источнику перед
  публикацией** — формулировка рекламная и нигде у производителя не подтверждена.
- В прайсе Zilma идёт строками **«Краска д/волос тон µ»** (9 позиций на 11.09.2026).

## Общее по серии, уже использованное в статье о MATERIA

Чтобы не дублировать при написании следующих двух: буквенный код тона (тон-уровень),
21 тоновое семейство, три пропорции по уровням (1+1 / 1+2 / 1+3), разбор оксидантов
3 / 4,5 / 6% и приём «4,5% смешивается из 3% и 6%», расход состава, эмульгирование.

Брать именно оттуда, а не из поиска картинок: упаковка у бренда по регионам отличается, и
«похожее фото» легко оказывается другим рынком или прошлым дизайном.

**Скрипт, который собирал из них картинки для статьи о MATERIA, удалён намеренно.** В
статье стоят снимки, присланные пользователем (туба с упаковкой, оксиданты из PSD), а
скрипт при повторном запуске молча затирал их официальной композицией — ровно это один раз
и произошло. Понадобится сборка картинки из официальных фото — писать под конкретную
статью и не давать ей перезаписывать чужие файлы.
