# Оформление статей: блоки и ритм

Принято 16.10.2026 на статье о меди (`2026-10-15-copper-ginger-peach`). Олег: «гораздо интереснее
стало». Образец разметки — эта статья, стили — `src/pages/articles/[id].astro`.

## Зачем

Длинная статья из абзацев и таблиц подряд утомляет глаз: зацепиться не за что. Блоки делят текст на
куски, и каждый кусок видно сразу.

## Правила

- **Ритм:** не больше двух абзацев или таблиц подряд без яркого блока.
- **Цвет означает одно и то же во всех статьях:** зелёный (`callout tip`) — правило, которое помогает;
  янтарный (`callout warn`) — внимание, тут легко ошибиться; красный — ошибка (`fix-card`). Синий
  `callout` без модификатора — обычная заметка.
- **В карточках формул выделять только коды оттенков** (`<b>7/43</b>`), остальной текст обычный.
  Когда жирным был весь текст карточки, она читалась тяжело.
- Коды Igora с дефисом — через `&#8209;` (неразрывный дефис), иначе на телефоне «7-» и «77» разъезжаются.
- Таблицу оставлять, только если сравнение идёт по строкам и столбцам (коды по маркам, база → что
  учесть). Список «цель → формула» — это карточки.

## Порядок в начале статьи

1. Вступление и обложка.
2. `key-grid` «Коротко» — 4 главных правила (ровно 4 или 2: сетка 2×2, на телефоне один столбец).
3. `toc-box` — оглавление. Id заголовков брать из браузера (`document.querySelectorAll('h2')`),
   не угадывать.

## Блоки

| Блок | Для чего |
|---|---|
| `ul.key-grid > li` с `<b>заголовок</b>текст` | «Коротко» — главные правила |
| `nav.toc-box` | оглавление |
| `div.callout.tip` / `div.callout.warn` | правило / внимание |
| `div.formula-grid > div.formula-card` (`p.f-title` с `span.f-ox`, `p.f-codes`, `p.f-note`) | формулы: цель, окислитель, коды |
| `div.step-flow.compact > div.step` (`span.badge`, `span.step-icon`, `p`) | шаги без картинок; с картинками — `step-flow` без `compact` |
| `div.timer-chip` | время, пропорция одной строкой |
| `div.fix-list > div.fix-card` (`div.fix-bad` с `<b>` и `p.fix-why`, `div.fix-good`) | ошибки: что получилось → как исправить |
| `details.faq-item > summary` + `p.faq-a` | частые вопросы, раскрываются по нажатию |
| `mix-card`, `service-card`, `combo-grid`, `checklist` | как раньше |

## Проверка перед показом

- Ничего из текста не потерялось: сравнить цифры и коды до и после (на меди — сравнением токенов).
- **Внутри HTML-блока Markdown не работает:** `**жирный**` и `[ссылка](/…)` там видны как есть. В карточках и
  плашках писать `<b>` и `<a href>`. Проверка: на странице в `.prose` нет `**` и `](`; число ссылок до и
  после совпадает (поймано 16.10.2026 на колор-мелте).
- Ширина телефона 390: `document.documentElement.scrollWidth - innerWidth <= 0`.
- Таблицы заказа и кнопки «в заявку» не трогать: `update-article-kits.py` ищет таблицы по заголовкам `###`
  в разделе «Что заказать».
- Локальный сервер, проработавший сутки, может перестать видеть правки: `npx astro dev stop` и
  `npx astro dev --background`.
