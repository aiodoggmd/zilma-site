## Проверенный порядок

1. Сформировать новый Excel через `Price/build_price_current.py`, передав общий прайс, остатки и отдельный путь вывода.
2. Проверить новый файл: структура, товары, акции, категории, остатки; не перезаписывать старый до проверки.
3. После подтверждения заменить `public/prices/price-current.xlsx`.
4. Положить свежий файл остатков в `Site\Price\`, чтобы `scripts/xlsx-to-price-items.py` выбрал его как самый новый.
5. Запустить `python scripts/xlsx-to-price-items.py` — он обновляет `src/data/priceItems.json`, категории и журнал новинок.
6. Обновить дату в `src/data/prices.ts`.
7. Запустить `python scripts/verify-price-sync.py` — проверить статьи, товарные таблицы и интерактивные палитры.
8. Запустить `npm run build`.
9. Поднять локалку `npm run dev`; проверить главную, заказ, бренд, статью и скачивание Excel.
10. Проверить Git на секреты и лишние файлы, затем сделать коммит и `git push origin main` только после проверки пользователя.
