# Где искать готовые скиллы и MCP-серверы

Справочник. В правила не входит — читать, когда реально подбираем инструмент.
Проверено вживую 2026-08-16.

**Источники для поиска готовых скиллов/MCP-серверов** (смотреть предметно, когда станет ясно что именно нужно — не сейчас, не все подряд). Проверено вживую 2026-08-16, краткая характеристика по факту, не с чужих слов:
- **GitHub `modelcontextprotocol/servers`** — официальный репозиторий (управляется Anthropic вместе с сообществом). Сам репо держит только маленький набор эталонных серверов (Everything, Fetch, Filesystem, Git, Memory, Sequential Thinking, Time) + инструкции по установке (`npx`/`uvx`) и пример конфига `.mcp.json`. За полным списком серверов сообщества — ссылка на официальный MCP Registry. **Самый надёжный источник из списка.**
- **Smithery** (smithery.ai) — большой маркетплейс, 14 627+ MCP на момент проверки, сам разруливает OAuth/credentials при подключении. Установка через `npx smithery ...`. Много нишевых/специфичных серверов вперемешку с популярными (Context7, Exa Search и т.п.) — качество разное, проверять описание перед подключением.
- **Glama** (glama.ai/mcp/servers) — ещё больше, 72 476 серверов в реестре на момент проверки, у каждого есть оценки license/quality/maintenance (A/B/C) — удобно фильтровать мусор по этим оценкам перед тем как что-то подключать.
- **ClawHub** (clawhub.ai) — реестр «skills/plugins» для экосистемы **OpenClaw** (не подтверждено, что это то же самое, что скиллы Claude Code — другой продукт/бренд, проверять совместимость перед использованием). Всего 30 скиллов/12 плагинов на момент проверки, страница выглядела шумно/спамно (много повторяющегося декоративного текста) — доверять с осторожностью, не как основному источнику.
- **Hermes-agent skills** (`github.com/NousResearch/hermes-agent/tree/main/skills`) — реальный, активно обновляемый репозиторий (NousResearch), скиллы разложены по категориям: apple, autonomous-ai-agents, creative, devops/sdlc-review, email, github, media, mlops, note-taking, productivity, research, smart-home, social-media, software-development. Для «полезного сайта» вероятно интересны `productivity`, `software-development`, `social-media` — смотреть предметно когда будет ясна тема сайта.
- **mcp-hunt** — точную ссылку не подтвердил (`mcphunt.com` не открылся). Если пользователь хочет включить этот источник — прислать точный URL.
