Отдельно для новых посетителей — понятный путь «кто вы → что продаёте → почему у вас».
2. *Умный поиск как фишка сайта.* Развить нынешний поиск по прайсу до понимания запросов вида «wella 1.9» (все подходящие оксиды) или «холодный блонд» (подборка релевантных товаров+уходовых средств из разных линеек). — токенизация/точка-слэш сделаны 2026-08-27 (см. «Статус» выше), смысловые запросы — нет. **Новая идея пользователя (2026-08-27, ещё не сделано)**: тот же маленький поиск сделать и над интерактивной палитрой оттенков (`ShadeSwatchGrid.astro`) на страницах статей — сейчас там поиска нет вообще, только скролл по квадратам. Код токенизированного поиска из `PriceChecklist.astro` переиспользуется почти как есть.
3. *«Помощник колориста» — подбор по задаче.* Раздел с вопросом «что вы хотите сделать» (окрашивание/тонирование/нейтрализация/осветление/седина/уход) → сайт предлагает продукты под задачу.
4. *База знаний как отдельный продукт.* Текущий блок «Инфо» развить в «Базу колориста» с категориями (окрашивание/осветление/уход/технологии), позиционировать не как довесок к магазину, а как отдельный актив бренда.
5. *Связка статья → товары → заказ.* В каждой гид-статье — не только теория, но и блок «использованные продукты» с ценами и кнопкой «добавить всё в заявку» прямо из статьи.
6. *Постоянно видимая «Моя заявка».* Не только модалка по клику — плавающий элемент вида «🛒 Моя заявка — 7 товаров», всегда на экране, с итоговой суммой. — частично сделано 2026-08-27: на мобильной плашке навигации есть пункт «Корзина» с бейджем-счётчиком, теперь верно работающим на любой странице сайта (не только главной) благодаря переходу на localStorage (см. раздел «Статус» выше). Это переход к корзине, не постоянно развёрнутая сумма прямо на экране — сама идея полностью ещё не закрыта, но техническая база (корзина, живущая вне одной страницы) теперь есть.
7. *Осознанно НЕ делать классический интернет-магазин.* Явная рекомендация не тащить оплату картой/полноценную корзину/Ozon-подобный UX — B2B-модель «набрал → заявка → подтверждение по контакту» подходит лучше. **Согласуется с тем, что сайт и так уже устроен** — не новая идея, а подтверждение текущего направления.
8. *Статусы наличия вместо текста в названии.* Убрать «не заказывать!» и подобное из названий товаров (см. проверенный факт выше), сделать отдельными статус-метками: 🟢 в наличии / 🟡 под заказ / 🔴 нет в наличии / 🔥 акция / 🆕 новинка.
9. *Фильтры по оттенкам.* Для линеек вроде Shinefinity — фильтры по уровню (4–10), направлению (Natural/Ash/Pearl/Beige/Gold/Copper/Violet), эффекту (нейтрализация/холодный/тёплый/пастельный).
10. *Визуальные палитры оттенков.* Не список текстом, а кликабельные квадраты-образцы с карточкой оттенка (фото/описание/цена/наличие/активатор/рекомендации) по клику. — 🟡 **сделано на 2 из готовых линеек (Illumina, Shinefinity), 2026-08-27**, подробности в разделе «Статус» выше. Колестон — сложнее по структуре палитры, осознанно отложен. Londa/Color Touch — ещё не пробовали.
11. *«Формула → добавить всё».* Готовые рецепты (например «формула холодного блонда» — конкретные товары+граммовки) с одной кнопкой добавления всех компонентов в заявку.
12. *Усилить блок «Акции».* Подкатегории (скидка до 30%/распродажа/акция недели), обязательно показывать зачёркнутую старую цену рядом с новой, не просто новую цифру. — ✅ **сделано 2026-08-27**, подробности в разделе «Статус» выше (подкатегории по фактическим ступеням скидки 15%/7%, не по гипотетическим из идеи).
13. *«Новинки».* Отдельный фильтр/блок — что добавилось в прайс с последнего обновления. — ✅ **сделано 2026-08-27**, подробности в разделе «Статус» выше (в итоге — бейдж у товара, не отдельный блок/кнопка).
14. *«Избранное» / «Мой постоянный заказ» / «Повторить заказ».* Для мастеров, покупающих одно и то же регулярно — сохранённый набор товаров и кнопка «повторить», можно без полноценной авторизации (локальное хранилище браузера или именная ссылка).
15. *SEO-структура по URL.* Отдельные страницы-адреса вида `/wella/shinefinity/`, `/wella/shinefinity/09-65/`, `/blog/toning-after-lightening/` — каждая статья должна отвечать на конкретный рабочий вопрос мастера («как затонировать блонд после осветления»), это одновременно SEO и продажи.
16. *Telegram как полноценный канал сайта.* Явный блок-приглашение «ZILMA в Telegram» (цены/акции/новинки/формулы) со ссылкой с сайта.
17. *Уведомления о снижении цены.* Кнопка «следить за ценой» на товаре — уведомление, когда цена меняется (CRM-функция).
18. *Визуальная эстетика.* Минимализм: белый/глубокий красный/чёрный, чистая типографика — «профессиональная цифровая платформа», не «магазин косметики».
19. *Явное разделение двух аудиторий* (постоянный мастер vs новый посетитель) на уровне интерфейса — см. пункт 1.
20. *Отдельная страница «Для салонов».* B2B-лендинг внутри сайта: расходники, регулярные поставки, индивидуальные условия, форма заявки.
21. *Отдельная страница «Бренды».* Не только внутри прайса — красивая страница со списком брендов, переходом к линейкам каждого.
22. *Не прятать одноразовую продукцию/расходники.* Ассортимент реально широкий (одноразовая продукция, фольга, перчатки и т.п.) — показывать это как часть позиционирования «всё для салона», не стесняться.
