# Паспорт дизайна zilma.pro

Одна страница: цвета, шрифты, геометрия. Для всего, где нет кода: обложки постов в
Telegram, картинки в ChatGPT, бриф дизайнеру, второй сайт в том же стиле.

**Источник истины — `src/styles/global.css` (блок `:root`).** Этот файл — его выжимка,
составлена и сверена с кодом 24.09.2026. Роли цветов определены по тому, где они
реально стоят в компонентах, а не на глаз. Поменяли цвет в `global.css` — поправь и
здесь. Подробная история решений — `design-system.md`.

## Цвета

**Фирменные акценты**

| Цвет | HEX | Где стоит |
|---|---|---|
| Красный | `#c8000f` | фирменный: фон херо, значки «новинка», кнопка установки, полосы прогресса, раздел прайса |
| Тёмно-красный | `#8a000d` | сплошные значки в статьях (номера шагов, галочки), левый край градиента |
| Синий тёмный | `#38628c` | всё нажимаемое: кнопки, активные и наведённые фильтры, «скачать», «повторить заказ»; раздел инфо |
| Синий | `#4a7fa8` | пара к тёмному синему в градиенте |

Градиенты: херо — красный → синий (`#38628c` → `#4a7fa8` проявляется поверх красного);
шапка статьи в градиентном варианте — `135°, #c8000f → #38628c`.

**Текст**

| Цвет | HEX | Где стоит |
|---|---|---|
| Чернила | `#2b201c` | основной текст и заголовки — тёплый почти-чёрный, не `#000` |
| Приглушённый | `#9c948c` | подписи, надстрочники, даты |
| Кремовый | `#faf3ea` | текст на красном и синем фоне — вместо белого |

**Фоны и линии.** Сайт БЕЛЫЙ. От бежевого фона отказались в дизайне 05.09.2026 — не
возвращать. База `body` лишь на 4% теплее белого, а всё, что видит клиент (карточки,
панели, формы), — чистый белый. Для картинок и обложек фон брать белый `#ffffff`, не беж.

| Цвет | HEX | Где стоит |
|---|---|---|
| Бумага (основной фон) | `#ffffff` | карточки, панели, форма — доминирует на странице |
| Фон страницы | `#faf6f0` | `body`; тёпло-белый, почти неотличим от белого, НЕ беж |
| Панель | `#f1ece4` | панель статистики на странице бренда |
| Линия панели | `#e7e0d4` | разделители, линия у заголовков разделов |
| Рамка карточки | `#d8cfbf` | рамка карточки на белом |

**Пастель** — только для больших поверхностей, мелким элементам мало насыщенности:

| Цвет | HEX | Где стоит |
|---|---|---|
| Голубая поверхность | `#cbe3fb` | градиент `#e6f1fd → #cbe3fb`; колористика |
| Розовая поверхность | `#fae6ea` | градиент `#fdf3f6 → #fae6ea`; уход |
| Пастельный голубой | `#bcd8f2` | мелкое: колёса пропорций, активная вкладка фильтра, неактивная кнопка формы |
| Пастельный розовый | `#f3c1c9` | мелкое: колёса пропорций |

Редкие: `#f7b2ab` (коралл, 1 место), `#eceaf2` (туман, 4 места), `#6f665f` (один
серо-коричневый текст без переменной). `#98c5fc` и `#69a6fa` объявлены в `global.css`,
но нигде не используются.

## Шрифты

- **Заголовки — Playfair Display** (с засечками), жирность 600. Заголовок херо —
  `clamp(1.7rem, 3.2vw, 2.5rem)`; заголовки разделов — 1.3rem, ПРОПИСНЫМИ, разрядка 0.03em.
- **Текст — Inter**, запасные Segoe UI → системный.
- **Надстрочники** — Inter 0.72rem, 600, прописные, разрядка 0.09em, приглушённый цвет.
- Где Playfair нет (картинки, PIL) — Georgia Bold.

## Геометрия

- Скругление: **6px** — карточки и панели, **4px** — кнопки и мелочь. Пилюль нет
  (кроме счётчика корзины). Стиль — прямоугольный, «было 18px, попросили строже».
- Тени мягкие, тёплые: `0 2px 8px rgba(43,32,28,.07)`, при наведении
  `0 10px 28px rgba(43,32,28,.1)`.
- Ширина контента 1180px; поля 24px, на телефоне 16px.

## Правила, которые уже стоили переделок

- **Своих цветов не придумывать** — только из таблиц выше. Был случай с «подходящим»
  зелёным для галочек — убран.
- **Херо пастелью не красить** — красный → синий держит логотип.
- **Прайс — красный, инфо — синий.** Пастель в статье идёт по категории: колористика —
  голубая, уход — розовая.
- **Обложка статьи** — фото товара на белом, без текста и градиента.

## Для запроса в ChatGPT (картинки, обложки)

Вставлять в конец запроса как есть:

```
Background: clean WHITE (#ffffff). Do NOT use beige, cream or tan backgrounds.
Palette (use only these): brand red #c8000f, dark red #8a000d, deep blue #38628c,
blue #4a7fa8, ink text #2b201c (warm near-black, not pure black). Cream #faf3ea ONLY as
text color on red/blue fills, never as a background. Pastels only for large soft areas:
light blue gradient #e6f1fd→#cbe3fb, light pink gradient #fdf3f6→#fae6ea.
Headings in an elegant serif like Playfair Display, body in a clean sans like Inter.
Rectangular shapes with small 4–6px corner radius, soft warm shadows. Calm, premium,
professional salon-supply look on a white background. No neon, no pure black, no beige,
no extra colors.
```

## Баннеры через ИИ — что проверено (24.09.2026)

Прогнали этот паспорт через GPT, Gemini и Grok на баннере Londa Professional. Выводы:

- **Паспорт держит фон и стиль на всех трёх движках.** Белый фон, красная плашка,
  засечный заголовок в тёплых чернилах, иконки красным контуром — воспроизводятся везде.
  Ранняя ошибка (беж вместо белого) ушла после того, как в блок для ChatGPT первой строкой
  добавили «фон белый, беж не использовать». Роль фона в спецификации решает исход.
- **Упаковку ИИ рисовать НЕ давать — только реальным фото поверх.** Даже «на основе фото»
  все три движка перерисовывают коробку и гонят мелкий текст в кашу («Vitaflection
  Microspheres» → «CIATLEETION IIttEROPPHERES», туба зеркальной изнанкой). Издалека не
  видно, на увеличении — бессмыслица и дезинформация (ловит `site-image-auditor`).
  Схема: фон и оформление — от ИИ по паспорту, товар — настоящей фотографией сверху.
- **Логотип Zilma и `zilma.pro` ИИ достоверно не ставит** — накладывать отдельно на
  готовую картинку (мастер — `Site/favicon.png`, `logo.jpg`; оформление «булька» как в херо).
- **Иконки задавать по смыслу Zilma, а не Londa:** «Заказать / Доставка / Гарантия» (про
  поставщика) работают на нас лучше, чем «Яркий цвет / Уход / Седина» (достоинства краски).
- Готовый запрос под Gemini/Grok (плавным описанием сцены, не таблицей кодов) — движки
  вроде Gemini таблицу цветов читают как мусор; см. блок для ChatGPT выше, его же можно
  дать описанием.
