# Карусели Instagram из статей

`render_carousel.py` рисует слайды 1080×1350 в стиле сайта из JSON. Текст и коды рисует программа —
поэтому они точные; картинки (обложка) — готовые из статьи или Kling, без текста.

```
cd D:\Projects\work\Site
.venv\Scripts\python.exe tools\instagram\render_carousel.py <slides.json> <папка>
```

Получится `01.png…NN.png` и `contact-sheet.png` (все слайды миниатюрами — для проверки).
Пример: `example-slides.json`; рабочая карусель — `work/NEWS/instagram/2026-10-15-copper/`.

## Типы слайдов

| type | поля |
|---|---|
| `cover` | `title`, `subtitle`, `image` (путь от work/Site) |
| `text` | `title`, `body` (`\n` — новый абзац) |
| `cards` | `title`, `cards`: [{`title`, `body`, `tag`}] — 2–4 карточки |
| `fix` | `title`, `items`: [{`bad`, `why`, `good`}] — 1–3 строки «ошибка → исправление» |
| `keys` | `title`, `items`: [строки] — до 4 пунктов с номерами |
| `end` | `title`, `body` |

`**код**` в любом тексте — выделение медным жирным. Коды Igora — через неразрывный дефис `‑` (U+2011),
иначе «7-» и «77» могут разъехаться. Стрелки «→» не писать: в шрифте заголовков это вычурный знак.
Не влезает текст — программа остановится и назовёт его; сократить текст.

## Правила Instagram (проверено 16.10.2026)

- С 01.09.2025 реклама в Instagram в РФ запрещена (Meta признана экстремистской): никаких цен, «купить»,
  «акция», платного продвижения и блогеров. Экспертный контент своего аккаунта — можно (разъяснение ФАС
  от 25.07.2025). Нейтральная строка «Полная статья — zilma.pro» — допустима.
- Хештегов — не больше 5 (Instagram, с 18.12.2025).
- Шрифты Inter и Playfair Display — лицензия OFL (`fonts/`).
