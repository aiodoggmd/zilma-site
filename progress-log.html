Главная мысль

Не превращать сайт в «ещё один магазин косметики» — сила в том, что это рабочий инструмент мастера. Предложена рамка из четырёх ядер: 🛒 Купить (каталог+прайс+заявка), 🎨 Подобрать (палитры+фильтры), 🧪 Рассчитать (формулы+пропорции), 📚 Узнать (база знаний+статьи) — всё связано между собой. Пример сценария: ищешь оттенок → видишь товар → видишь формулу → видишь активатор → «добавить всё в заявку».

Навигация и поиск

Три главные кнопки на входе (Каталог / Прайс Excel / Акции) вместо «разбирайся сам». Два режима: «я знаю что нужно» (быстрый поиск) и «я хочу посмотреть» (каталог по брендам → линейкам).

Развить поиск до понимания запросов вида «wella 1.9» (все подходящие оксиды) или «холодный блонд» (подборка из разных линеек) — не только точное совпадение по названию.

Явно развести два сценария на уровне интерфейса: постоянный мастер (цена→поиск→заявка) и новый посетитель (кто вы→что продаёте→почему у вас).

Помощник колориста и база знаний

Раздел «что вы хотите сделать» (окрашивание/тонирование/нейтрализация/осветление/седина/уход) — сайт предлагает продукты под задачу.

Текущий блок «Инфо» развить в полноценную «Базу колориста» по категориям — как отдельный актив бренда, не довесок к магазину.

В каждой гид-статье — блок «использованные продукты» с ценами и кнопкой «добавить всё в заявку» прямо из статьи.

Готовые «формулы» (например «формула холодного блонда» — конкретные товары и граммовки) с одной кнопкой добавить всё в заявку.

✓ провереноУбрать текст вроде «не заказывать!» из названий товаров (реальный случай нашёлся) — сделать отдельными статус-метками: в наличии / под заказ / нет в наличии / акция / новинка.

Фильтры по оттенкам (уровень, направление, эффект) для линеек вроде Shinefinity.

Визуальные палитры — кликабельные квадраты-образцы оттенков вместо текстового списка.

Не прятать одноразовую продукцию/расходники — показывать как часть позиционирования «всё для салона».

Заявка, акции, повторные покупки

Постоянно видимый плавающий элемент «Моя заявка — N товаров», не только модалка по клику.

Усилить «Акции»: подкатегории, обязательно зачёркнутая старая цена рядом с новой.

«Новинки» — что добавилось в прайс с последнего обновления.

«Избранное» / «мой постоянный заказ» / «повторить заказ» — можно без полноценной авторизации, через локальное хранилище браузера.

Уведомление «следить за ценой» на товаре — CRM-функция, сообщать при изменении цены.

Каналы, страницы, визуал

Явный блок-приглашение «ZILMA в Telegram» со ссылкой с сайта.

Отдельная страница «Для салонов» — B2B-лендинг (расходники, регулярные поставки, индивидуальные условия).

Отдельная красивая страница «Бренды» со списком и переходом к линейкам каждого.

Визуальный минимализм (белый/глубокий красный/чёрный, чистая типографика) — «профессиональная платформа», не «магазин косметики».

Осознанно НЕ делать

Классический интернет-магазин с оплатой картой и полноценной корзиной — B2B-модель «набрал → заявка → подтверждение» подходит лучше. Это подтверждает уже выбранное направление, а не новая идея.

Приоритеты по этапам (ориентир из отчёта, не обязательство)

🔴 Этап 1Навигация, мощный поиск, отдельный каталог, страницы брендов, карточки товара, статусы наличия, постоянная «Моя заявка».

🟠 Этап 2Палитры, фильтры оттенков, формулы колориста, «добавить всё из формулы», избранное, повторный заказ.

🟡 Этап 3База знаний, SEO-статьи, связка статья↔товары, подбор по задаче, помощник колориста.

🟢 Этап 4Telegram-интеграция, уведомления о ценах, персональные предложения, история заказов, B2B-кабинет.

От себя: большая часть этапов 1-2 — реально крупные фичи (умный поиск, палитры-конструктор, формулы с автодобавлением — это уже смена структуры данных прайса, не косметика). Прежде чем брать что-то в работу, стоит вместе решить масштаб и бюджет — не начинать молча с «очевидных» первых пунктов.
