**Matrix SoColor Pre-Bonded** — перманентный крем-краситель со встроенным бондером: закрашивание седины, предсказуемая работа с фоном осветления и подъём до 4 уровней тона за одно окрашивание. Формулы самонастраивающиеся — оттенок предварительно смешан с базой, отдельно добавлять её не нужно.

Под одним названием живут **три коллекции с разной техникой смешивания** — это главное, что нужно держать в голове: перепутать пропорцию здесь легко, а результат разойдётся с ожиданием.

<div class="callout"><b>Бондер в составе.</b> Защищает внутреннюю структуру волоса прямо во время окрашивания — качество сохраняется от процедуры к процедуре, без отдельного шага и без доплаты за него.</div>

    <ul>
      <li><b>1:2</b> с оксидантом <b>9%</b> — максимальная нейтрализация</li>

<div class="callout"><b>Частая ошибка.</b> Ultra Blond смешивается <b>1:2</b>, а не 1:1, как остальные коллекции. Разведённый «как обычно» ультра-блонд не даст заявленного подъёма.</div>

<ul class="checklist">
  <li><span class="check-icon">✓</span>Не наносить на тонкие волосы вдоль линии роста</li>
  <li><span class="check-icon">✓</span>UL-AA, UL-VV, UL-A+ — только на последние 10–15 минут</li>
  <li><span class="check-icon">✓</span>Для мелирования отделять тонкие пряди — для полной пропитки</li>

## Выбор оксиданта

Крем-оксидант Matrix и его действие:

| Оксид | Что делает |
| --- | --- |
| 3% (10 V) | тон в тон, без подъёма |
| 6% (20 V) | поднимает на 1 уровень |
| 9% (30 V) | поднимает на 2 уровня |
| 12% (40 V) | поднимает на 3–4 уровня (зависит от формулы) |

## Подбор оттенка — три правила

<ol>
<li><b>Определите натуральный уровень тона</b> волос клиента.</li>
<li><b>Определите желаемый уровень</b> — светлее, темнее или на том же уровне.</li>
<li><b>Определите желаемое отражение</b> — холодное, нейтральное или тёплое.</li>
</ol>

<div class="callout"><b>Фон осветления.</b> С повышением уровня тона он меняется от красного через оранжевый к жёлтому. Нейтрализуют его дополняющие цвета: зелёный гасит красный, синий — оранжевый, фиолетовый — жёлтый.</div>

## Система нумерации оттенков

Код строится как «уровень + буквенное отражение»: **8NW** — светлый блондин натуральный тёплый.

### Число — глубина тона

| Уровень | Цвет |
| --- | --- |
| **1** | Иссиня-чёрный |
| **2** | Чёрный |
| **3** | Тёмный шатен |
| **4** | Шатен |
| **5** | Светлый шатен |
| **6** | Тёмный блондин |
| **7** | Блондин |
| **8** | Светлый блондин |
| **9** | Очень светлый блондин |
| **10–11** | Самые светлые уровни |

### Буква — отражение

| Код | Отражение |
| --- | --- |
| **N** | Натуральный |
| **NW** | Натуральный тёплый |
| **A** | Пепельный (Ash) |
| **AV** | Пепельно-фиолетовый |
| **SP** | Серебристо-жемчужный |
| **P** | Жемчужный |
| **V** | Фиолетовый |
| **W** | Тёплый |
| **G** | Золотистый |
| **C** | Медный |
| **R** | Красный |
| **M** | Мокка |
| **BR** | Коричневый |

<div class="callout"><b>Двойная буква</b> (MM, RR, VV) — усиленное отражение. <b>Знак «+»</b> (UL-A+, 4RV+) — повышенная интенсивность.</div>

<div class="callout"><b>Коды 504–510</b> — коллекция Extra Coverage. Последние две цифры показывают глубину тона: 504 — уровень 4, 510 — уровень 10.</div>
