# Переезд сайта на российский хостинг

## Зачем

Две причины, и вторая важнее первой.

1. **Сайт не открывается с мобильного интернета.** Проверено 10.09.2026 на реальной
   симке: по Wi-Fi открывается, по мобильному — нет, при этом другие российские сайты
   на той же симке работают. Vercel раздаёт сайт из Франкфурта (`X-Vercel-Id: fra1`),
   и у оператора этот маршрут перекрыт. Аудитория сайта — мастера, которые смотрят
   прайс с телефона между клиентами: для них сайта сейчас нет.
2. **152-ФЗ.** С 1 июля 2025 имя и телефон россиянина не должны впервые записываться
   на сервере за пределами РФ. Сейчас форма отправляет их на функцию Vercel.

Переезд закрывает обе разом.

## Что покупать

Обычный виртуальный хостинг **в SpaceWeb** — там уже зарегистрирован домен `zilma.pro`,
значит DNS менять не придётся, только переключить запись на хостинг. Ориентир 250–350 ₽
в месяц. Требования у нас скромные: PHP 8, 1 ГБ места, `mod_deflate` (есть везде).

Решение и оплата — за владельцем бизнеса: оператором персональных данных считается он,
а не сотрудник.

## Что уже готово в этой папке

| Файл | Что делает |
|---|---|
| `order.php` | принимает заявку, кладёт её в РФ, шлёт в Telegram уведомление без персданных |
| `orders.php` | просмотр заявок по паролю: имя, телефон, состав, вложение |
| `config.example.php` | настройки — скопировать в `config.php` и заполнить |
| `.htaccess` | **сжатие**, кэш, https и www, 404, защитные заголовки |
| `astro.config.static.mjs` | конфиг сборки без Vercel |
| `../scripts/deploy-to-hosting.py` | выкладка собранного сайта по FTP |

## Порядок переезда (примерно вечер)

1. **Купить хостинг**, получить FTP-доступ.
2. **Разложить файлы:**
   - `public_html/` — содержимое `dist/` после сборки, плюс `.htaccess`, `order.php`, `orders.php`;
   - `zilma-data/` — **рядом с `public_html`, не внутри!** Сюда лягут заявки. Внутри их
     можно было бы открыть прямой ссылкой.
   - `config.php` — тоже вне `public_html`.
3. **Собрать сайт статикой:** заменить `astro.config.mjs` на `deploy/astro.config.static.mjs`,
   удалить `src/pages/api/order.ts`, убрать `<Analytics />` и `<SpeedInsights />` из
   `BaseLayout.astro`, поменять адрес отправки формы в `OrderForm.astro` на `/order.php`.
4. **Выложить** и проверить сайт по техническому адресу хостинга, ДО переключения домена.
5. **Переключить DNS** в панели SpaceWeb: `A`-запись на IP хостинга, `www` туда же.
   Записи Vercel убрать. Разъезжается по интернету от получаса до суток.
6. **Выпустить SSL** (Let's Encrypt, в панели бесплатно) и дождаться https.
7. **Проверить по списку ниже.**
8. **Отключить домен в Vercel** — чтобы проект не пытался его обслуживать.

## Проверка после переезда

- [ ] Сайт открывается **с мобильного интернета без VPN** — ради этого всё и затевалось.
- [ ] Сжатие работает: `curl -sI -H 'Accept-Encoding: gzip' https://www.zilma.pro/ | grep -i content-encoding`
      должно вернуть `gzip`. Если пусто — главная едет как 2,5 МБ вместо 110 КБ.
- [ ] Тестовая заявка доходит, в Telegram приходит уведомление **без имени и телефона**.
- [ ] По ссылке из уведомления заявка открывается после ввода пароля.
- [ ] Файл заявки НЕ открывается прямой ссылкой из браузера.
- [ ] Каталог, поиск по коду оттенка, палитры в статьях, скачивание прайса, повтор заказа.
- [ ] `https://www.zilma.pro/sitemap-index.xml` отдаётся, адреса страниц не изменились.
- [ ] Старый адрес прайса и адреса статей работают: они уже в индексе Яндекса и Google.
