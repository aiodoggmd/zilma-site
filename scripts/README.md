# Скрипты проекта

Две полки. Первая — то, что запускается регулярно; вторая — сделанное под конкретную
задачу и оставленное как образец для следующего раза.

Файлы и папки с `_` в начале — **исходные данные**, а не скрипты: на них ссылаются
сборщики палитр, перекладывать их нельзя.

## Постоянные — запускаются регулярно

| Скрипт | Что делает | Как зовут |
|---|---|---|
| `publish.py` | весь ритуал публикации: сборка → проверки → план → заливка по FTPS | `npm run publish`, с `--apply` для заливки |
| `morning-check.py` | утренняя проверка живого сайта | `npm run check` |
| `deploy-to-hosting.py` | заливка файлов на SpaceWeb (вызывается из `publish.py`) | через `publish.py` |
| `deploy-config.py` | доступы к хостингу, читает `.env.deploy` | вызывается другими |
| `xlsx-to-price-items.py` | собирает `src/data/priceItems.json` из готового прайса | шаг 5 ритуала прайса |
| `verify-price-sync.py` | сверяет прайс с данными сайта, даёт сводку | внутри `publish.py` |
| `migrate-renamed-products.py` | переносит журналы и палитры при переименованиях товаров | шаг 3 ритуала прайса |
| `suggest-categories.py` | подсказывает категории для новых товаров | по необходимости |
| `optimize-image.py` | пережимает картинку в `.webp` под нужный размер | по необходимости |

Полный ритуал обновления прайса — в `../AGENTS.md`, раздел «ОБНОВЛЕНИЕ ПРАЙСА».

## Одноразовые — образцы для следующего раза

| Скрипт | Под какую задачу делался |
|---|---|
| `build-materia-shades.py` | палитра Lebel MATERIA |
| `build-supersync-shades.py` | палитра Matrix SoColor Sync |
| `build-tonalcontrol-shades.py` | палитра Matrix Tonal Control |
| `build-colorsync-shades.py` | палитра Matrix Color Sync |
| `extract-colorsync-swatches.py` | нарезка свотчей с картинки палитры |
| `regroup-socolor-palette.py` | перегруппировка палитры SoColor |
| `extract-archive-photos.py` | вытаскивание товарных фото из архива старого сайта |
| `build-app-icons.py` | иконки PWA |
| `telegraph-to-md.py` | перенос статьи из Telegraph в Markdown |

**Новая линейка красителя — не пиши с нуля.** Скопируй ближайший по структуре палитры
`build-*-shades.py` и правь под свой источник. Замерено 11.09.2026: общего кода у этих
четырёх — от 4% до 28%, у каждой линейки свой разбор картинки. Поэтому они и не сведены
в один скрипт с флагом: единый парсер пришлось бы писать заново под четыре разных
формата, а это риск сломать уже опубликованные палитры без выигрыша.
